# جبل الرماة

تطبيقٌ شخصيّ لخطة عائشة العلمية والمهارية: وِرد اليوم، ومنهج ماجستير الحديث بفصلَيه، والمهارات، والقراءة، وصناعة المحتوى، مع سجلٍّ للثبات وتنبيهاتٍ يومية.

## الإعداد (مرةً واحدة، نحو عشر دقائق)

### ١. رفع الملفات
1. أنشئي حسابًا على github.com إن لم يكن لديكِ.
2. أنشئي مستودعًا جديدًا عامًّا باسم `jabal-alrumat`.
3. اختاري **Add file ← Upload files**، واسحبي محتويات هذا المجلد كلَّها، ومنها مجلد `.github` (إن لم يظهر لكِ لأنه مخفيّ، فأنشئي الملف يدويًّا: **Add file ← Create new file** باسم `.github/workflows/reminders.yml` والصقي محتواه).
4. اضغطي **Commit changes**.

### ٢. تشغيل التطبيق على الويب
1. في المستودع: **Settings ← Pages**.
2. تحت *Branch* اختاري `main` والمجلد `/ (root)` ثم **Save**.
3. بعد دقيقةٍ أو اثنتين يصير التطبيق على: `https://اسم-المستخدم.github.io/jabal-alrumat/`

**التثبيت على الهاتف:**
- آيفون: افتحي الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- أندرويد: افتحيه في Chrome ← القائمة ⋮ ← «تثبيت التطبيق».

### ٣. التنبيهات عبر ntfy
1. ثبّتي تطبيق **ntfy** من App Store أو Google Play.
2. اختاري اسمًا خاصًّا للقناة يصعب تخمينه، مثل `jabal-aisha-7k2q9`، واشتركي فيه من داخل ntfy (زر ＋).
3. في المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**
   - Name: `NTFY_TOPIC`
   - Secret: اسم القناة نفسه.
4. للتجربة: **Actions ← تنبيهات جبل الرماة ← Run workflow**، فيصلكِ تنبيهٌ تجريبي.

> إن رأيتِ في تبويب Actions زرًّا يطلب تفعيل المهامّ (I understand my workflows…)، فاضغطيه أولًا.

**تيليجرام بدلًا من ntfy أو معه (اختياري):** أنشئي بوتًا عبر @BotFather، وأضيفي السرّين `TELEGRAM_TOKEN` و`TELEGRAM_CHAT_ID`.

## مواعيد التنبيهات (بتوقيت الكويت)

| الوقت | التنبيه |
|---|---|
| ٣:٣٠ ص | الوتر، ووجه اليوم أو التثبيت |
| ٦:٠٠ ص | أذكار الصباح، وماجريات، وخطة اليوم، والاختبار الشهري في يومه |
| ٨:٠٠ ص | الضحى، وكتاب الحديث لليوم |
| ١١:٠٠ ص | مهارات اليوم |
| ٣:٤٥ م | أذكار المساء |
| ٦:١٥ م | محاسبة اليوم |

قد يتأخّر GitHub في تشغيل المهامّ المجدولة بضع دقائق، وأحيانًا أكثر في أوقات الذروة.

## ملاحظات
- بيانات التقدّم محفوظةٌ في هاتفكِ وحده. انسخي نسخةً احتياطية من الإعدادات بين حينٍ وآخر.
- تعديل أيام البنود داخل التطبيق لا يغيّر نصّ التنبيهات؛ نصوصها في `scripts/notify.mjs`.
- يوقف GitHub المهامّ المجدولة بعد ٦٠ يومًا بلا نشاط، والمهمّة تُحدّث ملفًّا صغيرًا أول كل شهر لتبقى حيّة.
